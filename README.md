 Mond: Daemon dylib injector untuk proses SpringBoard.
 3105: Live memory patcher untuk modifikasi biner langsung.
 Gestalt Edit: Manipulasi parameter ⁠libMobileGestalt⁠.
 Ketamine & Restart Engine: Penanganan userspace reboot untuk menerapkan perubahan Feature Flags secara permanen.
 Liquid Glass Control: Modul khusus untuk menonaktifkan efek transparan Liquid Glass pada iOS 27 Beta 1-4.
